# Lab 05 — Change the Layout of the HTML with CSS

COS10026 Web Technology Project · Week 05 lab exercise.

`lab05.html` is the page supplied with the lab. It links three external style sheets, read in this order:

1. `styles/lab04.css` — the typographic styles from the week 04 lab.
2. `styles/layout.css` — the layout for this lab: the box model (border, margin, padding,
   background graphic) on the aside and header, floats and `clear` for the two-column sections,
   widths in percentages, a minimum width on the article, and `:first-child`, `:nth-child(2)` and
   `:last-child` rules for the footer.
3. `styles/dl.css` — the supplied style sheet for the definition list, with the `::after` pseudo element.

`styles/images/fade.jpg` is the background graphic used by the CSS; images used by the HTML stay in `images/`.

`index.html` is an identical copy of `lab05.html`, so the site root shows the styled page.
